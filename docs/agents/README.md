# Sistema de Gestión de Préstamos y Recaudo Diario

Este paquete contiene los archivos Markdown base para iniciar el proyecto del sistema de recaudo diario.

## Archivos incluidos

1. `00_contexto_sistema_recaudo_diario.md`  
   Contexto funcional y reglas generales del sistema.

2. `01_agente_backend.md`  
   Prompt completo para el agente encargado de construir el backend.

3. `02_agente_frontend.md`  
   Prompt completo para el agente encargado de construir el frontend.

4. `03_historias_usuario_backend.md`  
   Historias de Usuario del backend.

5. `04_historias_usuario_frontend.md`  
   Historias de Usuario del frontend.

6. `05_backlog_mvp_priorizado.md`  
   Orden recomendado para iniciar el MVP.

## Objetivo del sistema

Construir una plataforma para gestionar rutas de cobro diario, clientes, préstamos, abonos, caja de trabajadores, auditoría y administración general.

El trabajador podrá crear clientes y préstamos directamente desde su ruta, manteniendo el orden real del recorrido. El administrador tendrá control sobre rutas, trabajadores, préstamos, pagos, caja, mora, límites y auditoría.
